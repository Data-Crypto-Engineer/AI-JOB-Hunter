# AI-JOB-Hunter
AI Job Hunter — a Streamlit app that reads your resume, uses Gemini to infer explicit and hidden skills, generates diverse search queries, and pulls live remote job listings from RemoteOK, Working Nomads, We Work Remotely, Greenhouse, Lever, Adzuna, and Jooble. AI ranks each match, explains why it fits, flags missing skills, and exports results.
